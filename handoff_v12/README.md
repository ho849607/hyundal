# DriveCheck 개발 전달 패키지

프로젝트명은 DriveCheck, 아이템명은 차량 위기 대응 및 사고 기록 서비스다. 화면 기준은 v12, 개발 범위는 이번 정리본의 P0~P2를 따른다.

| 파일 | 내용 |
| --- | --- |
| [rules/DriveCheck_MVP_Rules.md](rules/DriveCheck_MVP_Rules.md) | 코딩 우선순위, 상태 전이 UML, 데이터 규칙, 완료 기준 |
| [rules/HMG_Pleos_Integration.md](rules/HMG_Pleos_Integration.md) | 현대 차량 데이터와 API, 개발 환경, 제출 요건 |
| [rules/DriveCheck_Requirements_v12.md](rules/DriveCheck_Requirements_v12.md) | 기존 화면·디자인과 전환 규칙 원본 |
| [rules/Demo_Video_Script.md](rules/Demo_Video_Script.md) | 목소리 입력과 시연 영상 촬영·편집 순서 |
| [screens/INDEX.md](screens/INDEX.md) | P0 우선 화면 및 전체 PNG 목록 |

기존 PNG와 요구사항에는 P1·P2 디자인도 포함된다. 개발을 시작할 때는 MVP 규칙으로 범위를 확인하고, 대응 PNG를 열어 문구·배치·전환을 맞춘다. 시연에서 차량·통화·전송 테스트 입력은 모의 출처를 표시한다. 앱에서 119에 직접 발신하거나 차량 제어를 수행하는 코드는 승인된 별도 연동에서만 검토한다.
