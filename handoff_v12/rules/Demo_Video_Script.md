# DriveCheck 시연 영상 제작안

먼저 M0~M4를 확인한다. 아래는 가로 16:9, 약 60초를 가정한 선택 제출용 시연 영상의 대본이다. 영상 길이는 팀 편집안이다. 별도 숏폼은 공모전 숏폼 가이드에서 형식과 게시 요건을 확인한다.

| 시간 | 화면 | 사용자 목소리와 자막 |
| --- | --- | --- |
| 00–07초 | 차량 앱 시작, 제목과 문제 제시 | 내레이션 “운전자가 대답할 수 없을 때, 동승자는 어디에 어떻게 도움을 요청해야 할까요?” |
| 07–19초 | 마이크 입력 → 인식 자막 → 운전자 상태 미확인과 큰 119 | 동승자 역할 “운전하는 엄마가 대답을 안 해요.” 실제 STT를 쓴 장면이면 녹음과 인식 결과가 함께 보이게 한다. |
| 19–34초 | “119 전화” → 발신 화면 → 모의 연결 → 위치 확인 | 동승자 역할 “119 전화.” 화면 표시 ‘119 연결 상태 시뮬레이션’. 위치가 모의 데이터이면 그것도 표시한다. |
| 34–46초 | 위치 확인 시각과 연결 결과, 실차 권한 확인 범위 안내 | 내레이션 “연결 상태와 위치의 확인 여부를 따로 보여 줍니다.” |
| 46–57초 | 같은 사건 ID → 시간순 기록 → PDF 공유 화면 | 내레이션 “정차한 뒤에는 차량 관측과 동승자 진술, 대응 결과를 같은 기록에서 확인합니다.” |
| 57–60초 | 프로젝트명과 아이템명 | 자막 ‘DriveCheck · 차량 위기 대응 및 사고 기록 서비스’. |

## 촬영과 편집

1. 실제 에뮬레이터에서 음성 입력이 가능하면 사용자의 발화를 마이크에 입력해 화면과 함께 녹화한다. 녹음 파일로 재현하거나 화면 목업을 사용할 때는 영상에 해당 방식을 표시한다.
2. 목소리 소스는 내레이션과 동승자 대사를 각각 WAV 또는 M4A로 녹음한다. 실제 아동 목소리 없이 팀원이 재연할 수 있다. 공식 양식의 익명 심사 범위에 맞춰 영상·공유 링크에 팀원 실명·연락처·계정 정보가 노출되지 않게 한다.
3. 모의 전화·충돌·기관 전송은 해당 구간에 자막으로 표시하고 가상의 위치·사건 ID를 사용한다. 화면과 자막을 대조하고 119 등 실제 외부 통화는 시연에 사용하지 않는다.
4. 개발 전 목업을 제출하는 경우 제목 또는 시작 카드에 ‘프로토타입 시연’을 표시한다. 2차 PT에는 실제 실행 앱 시연을 별도로 준비한다.
